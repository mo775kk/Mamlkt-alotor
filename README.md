# مملكة العطور | MAMLKAT AL-OTOR

المتجر يعمل بواجهة عربية RTL وهوية ملكية سوداء وذهبية، مع فهرس واضح للأقسام من الصفحة الرئيسية.

## الملفات الفعالة
- `index.html` — صفحة المتجر والفهرس والأقسام والسلة والنوافذ.
- `style.css` — ملف التصميم الوحيد للواجهة، ويشمل الهاتف والكمبيوتر.
- `app.js` — وظائف البحث والكتالوج والتفاصيل والمفضلة والسلة وطلبات واتساب.
- `data/products.json` — المصدر الأساسي لمنتجات المتجر.
- `oil-catalog-public.json` — كتالوج مرجعي منفصل للزيوت الموردة.
- `sw.js` و`manifest.webmanifest` — تثبيت التطبيق وتحديث التخزين المؤقت.

## قواعد البيانات والأسعار
- لا يتم اختراع مخزون أو أسعار أو نوتات عطرية.
- المنتج الذي يحمل `needsReview: true` أو `available: false` يظهر على أنه يحتاج تأكيدًا، ويمكن للعميل إرسال استفسار عنه دون احتساب سعر وهمي.
- لا تتم إضافة المنتج إلى سلة الشراء بسعر إلا إذا كان معتمدًا ومتوفرًا في البيانات.
- جدول أحجام الزيت الافتراضي: 3 مل = 50 ج.م، 5 مل = 75 ج.م، 10 مل = 100 ج.م. الأسعار المرجعية لا تعني توفر المخزون.
- مفاتيح التخزين المحلي محفوظة للتوافق: `mamlaka_products`, `mamlaka_cart`, `mamlaka_wishlist`.

## تشغيل التحقق
```bash
node --check app.js
node --check sw.js
node scripts/smoke-check.mjs
node scripts/ai-worker-test.mjs
```
