# مملكة العطور | MAMLKAT AL-OTOR

واجهة متجر ثابتة جاهزة للنشر على GitHub Pages، بتصميم داكن ذهبي وصورة الواجهة التي أرسلها صاحب المشروع.

## الملفات
- `index.html`: بنية الصفحات.
- `styles.css`: التصميم المتجاوب.
- `app.js`: البحث والسلة والمفضلة ومختبر التركيب والمستشار القائم على قواعد وواتساب.
- `assets/images/royal-hero.jpg`: صورة الواجهة المرفقة.
- `data/products.json`: نموذج بيانات قابل للتوسعة.

## التشغيل المحلي
افتح `index.html` في متصفح حديث. الأفضل تشغيل خادم محلي بسيط إذا أضفت لاحقًا تحميل JSON ديناميكيًا. النسخة الحالية لا تحتاج إلى تحميل JSON منفصل كي تعرض بياناتها الأولية.

## النشر على GitHub Pages
1. فك ضغط الملف.
2. افتح المستودع الصحيح على GitHub وخذ نسخة احتياطية من الملفات الحالية.
3. ارفع محتويات المجلد إلى جذر الفرع المستخدم للنشر، مع بقاء `index.html` في الجذر.
4. من Settings → Pages اختر الفرع والمجلد الصحيحين (عادةً `main` و`/(root)`).
5. انتظر اكتمال النشر ثم افتح رابط الموقع واختبره على الهاتف والكمبيوتر.

## مهم قبل الاستخدام التجاري
- أسماء المنتجات المعروضة تجريبية/أولية وتحتاج مراجعة؛ الأسعار غير المحددة لا تسمح بالإضافة إلى السلة.
- الأسعار الافتراضية لمختبر التركيب مرجعية، ويجب تأكيد السعر والتوفر عبر واتساب.
- لوحة إدارة مركزية غير مضمنة في هذه النسخة؛ يلزم خادم/قاعدة بيانات ومصادقة آمنة لتحديث بيانات جميع الزوار.
- بيانات السلة والمفضلة وطلبات العطور غير الموجودة تحفظ محليًا في المتصفح فقط.
- مستشار العطور الحالي قائم على مطابقة الكلمات محليًا، وليس اتصالًا بنموذج ذكاء اصطناعي.
- البحث الصوتي يعتمد على دعم المتصفح والإذن.
- لا توجد بوابة دفع أو تسجيل طلبات مركزي في هذه النسخة.
- لا تضع مفاتيح API أو كلمات مرور في ملفات الواجهة العامة.

## قائمة اختبار يدوي
- شاشة المقدمة وتخطيها.
- البحث والتصفية.
- فتح تفاصيل المنتج.
- تجربة المفضلة والسلة.
- تغيير حجم مختبر التركيب.
- إرسال رسالة واتساب.
- تبديل اللغة.
- تجربة العرض على الهاتف.
