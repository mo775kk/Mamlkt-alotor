# مملكة العطور | MAMLKAT AL-OTOR

واجهة متجر ثابتة جاهزة للنشر على GitHub Pages، بتصميم داكن ذهبي وصورة الواجهة التي أرسلها صاحب المشروع.

## الملفات
- `index.html`: بنية الصفحات.
- `styles.css`: التصميم المتجاوب.
- `app.js`: البحث والسلة والمفضلة ومختبر التركيب والمستشار القائم على قواعد وواتساب.
- `assets/images/royal-hero.jpg`: صورة الواجهة المرفقة.
- `data/products.json`: نموذج بيانات قابل للتوسعة.

## التشغيل المحلي
افتح `index.html` في متصفح حديث. الأفضل تشغيل خادم محلي بسيط إذا أضفت لاحقًا تحميل JSON ديناميكيًا. النسخة الحالية لا تحتاج إلى تحميل JSON منفصل كي تعرض بياناتها الأولية.

## النشر على GitHub Pages
1. فك ضغط الملف.
2. افتح المستودع الصحيح على GitHub وخذ نسخة احتياطية من الملفات الحالية.
3. ارفع محتويات المجلد إلى جذر الفرع المستخدم للنشر، مع بقاء `index.html` في الجذر.
4. من Settings → Pages اختر الفرع والمجلد الصحيحين (عادةً `main` و`/(root)`).
5. انتظر اكتمال النشر ثم افتح رابط الموقع واختبره على الهاتف والكمبيوتر.

## مهم قبل الاستخدام التجاري
- أسماء المنتجات المعروضة تجريبية/أولية وتحتاج مراجعة؛ الأسعار غير المحددة لا تسمح بالإضافة إلى السلة.
- الأسعار الافتراضية لمختبر التركيب مرجعية، ويجب تأكيد السعر والتوفر عبر واتساب.
- لوحة إدارة مركزية غير مضمنة في هذه النسخة؛ يلزم خادم/قاعدة بيانات ومصادقة آمنة لتحديث بيانات جميع الزوار.
- بيانات السلة والمفضلة وطلبات العطور غير الموجودة تحفظ محليًا في المتصفح فقط.
- مستشار العطور الحالي قائم على مطابقة الكلمات محليًا، وليس اتصالًا بنموذج ذكاء اصطناعي.
- البحث الصوتي يعتمد على دعم المتصفح والإذن.
- لا توجد بوابة دفع أو تسجيل طلبات مركزي في هذه النسخة.
- لا تضع مفاتيح API أو كلمات مرور في ملفات الواجهة العامة.

متجر عطور رقمي بطابع دار عطور ملكية، لا قالب متجر عام. لوحة الألوان الأساسية: أسود فحمي #090807، ذهبي #D4AF37، ذهبي فاتح #F1D77A، ونص عاجي #F7F1E6. يمزج التوجيه البصري الخلفية الفوتوغرافية بأقنعة سوداء شفافة ولمسات ذهبية حتى تبقى القراءة واضحة ولا تتحول الصفحة إلى مساحة سوداء مسطحة. الصورة الافتراضية المستخدمة حاليًا هي assets/images/royal-hero.jpg، ويمكن لصاحب المتجر تحديد رابط صورة مباشر من إعدادات الموقع. يجب اختيار صورة مرخصة أو مملوكة للمتجر وضغطها للويب واختبارها على الهاتف.

الخطوط: Amiri للعناوين العربية، Tajawal للنصوص، وCormorant Garamond للهوية الإنجليزية. التصميم يجب أن يبقى سريعًا ومتجاوبًا، مع احترام تقليل الحركة، وعدم تكبير الصور تلقائيًا عند اللمس، وعدم استخدام زخارف أو رموز مشتتة بكثرة.

**أولوية 6 — التسويق:** تحسين SEO، بيانات Open Graph، صور مضغوطة وبدائل نصية، روابط اجتماعية صحيحة، تتبع زيارات يحترم الخصوصية، وصفحات منتجات قابلة للمشاركة.

## 10. سجل التقدم المحفوظ — 14 أكتوبر 2026

### التغييرات المضافة في هذه المرحلة
- تم ربط `enhancements.js` في `index.html` مع المحافظة على تحميل `app.js` و`settings.js`.
- تمت إضافة زر إغلاق (×) إلى إشعار الموقع، مع إخفاء تلقائي بعد 5 ثوانٍ، وإبقاء الإشعار متوافقًا مع كود الإشعارات الحالي.
- تمت إضافة دعم مفتاح Escape لإغلاق بعض الطبقات المفتوحة المدعومة، مثل السلة ونافذة المنتج ولوحة الإدارة عند توفر زر إغلاق مناسب.
- أضيفت أنماط تركيز مرئية لتحسين استخدام لوحة المفاتيح.
- تمت مراجعة الصياغة النحوية لملفات `app.js` و`settings.js` و`enhancements.js` بنجاح، والتأكد من ربط ملف التحسينات في الصفحة.

### ما لم يتم التحقق منه بعد
- لم يتم إجراء اختبار شامل داخل متصفح حقيقي لكل زر ونافذة؛ لذلك لا يُعد هذا السجل تأكيدًا بأن كل وظائف الموقع تعمل.
- يجب التأكد من سلوك الإشعارات مع كل أنواع الرسائل، ومن عدم تعارض زر × مع محتوى الإشعار في الاستخدام الفعلي.
- لا يزال محرر الأكواد الكامل والنشر المباشر الآمن إلى GitHub بحاجة إلى تكامل خلفي ومصادقة مناسبة.
- الإعدادات المخزنة في `localStorage` محلية للمتصفح والجهاز، وليست قاعدة بيانات مشتركة بين الأجهزة.
- المخزون والحسابات والطلبات المركزية والذكاء الاصطناعي المتصل بخدمة خارجية تحتاج إلى تنفيذ واختبار إضافيين.
- الخلفية الافتراضية المعروفة هي `assets/images/royal-hero.jpg`، مع إعدادات مظهر محفوظة محليًا؛ يجب اختبار مظهرها على الهاتف والحاسوب بعد النشر.

## مستشار مملكة العطور بالذكاء الاصطناعي
- أضيف `ai-service.js` كجسر آمن نسبيًا بين المستشار وخدمة API، مع استمرار الاقتراحات المحلية عند عدم تهيئة الخدمة أو تعذر الاتصال.
- أضيف خادم Cloudflare Worker داخل `ai-worker/src/index.js`، ويستخدم مفتاح `OPENAI_API_KEY` كـ Secret على الخادم فقط. لا تضع المفتاح في ملفات الواجهة أو GitHub.
- النشر غير مكتمل تلقائيًا: يجب نشر Worker وضبط المفتاح و`ALLOWED_ORIGINS`، ثم اختبار `/health`.
- تبويب «خدمة AI» في إعدادات المالك يحفظ رابط API في متصفح المالك فقط ويختبر الاتصال. لتفعيل الخدمة لدى جميع الزوار، ضع رابط Worker العام في `DEFAULT_ENDPOINT` داخل `ai-service.js` ثم انشر تحديث الموقع.
- الخدمة تستخدم بيانات الكتالوج المرسلة للترشيح فقط، ولا تضمن مخزونًا مركزيًا أو سعرًا غير مسجل. يلزم إضافة Rate Limiting أو Turnstile قبل الإطلاق التجاري.
- خطوات النشر التفصيلية: `ai-worker/README.md`.
