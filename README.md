# مملكة العطور | MAMLKAT AL-OTOR

متجر عطور عربي متجاوب يعمل بـ HTML وCSS وJavaScript، ومهيأ للنشر على GitHub Pages.

- الموقع: https://mo775kk.github.io/Mamlkt-alotor/
- المستودع: https://github.com/mo775kk/Mamlkt-alotor
- العنوان التجاري: الإسكندرية، شارع خالد بن الوليد
- واتساب: 01272776928

## بنية الملفات الأساسية

| الملف | المسؤولية |
|---|---|
| `index.html` | هيكل الصفحات والنوافذ ومناطق العرض |
| `site-unified.css` | ملف التصميم الموحد والمتجاوب |
| `theme-persistence.js` | تحميل الثيم وحفظ اختيارات العرض |
| `assets/js/site-catalog.bundle.js` | البحث والكتالوج والسلة والمفضلة والتركيب وتفاعل العميل |
| `assets/js/site-admin.bundle.js` | إعدادات الإدارة وتحرير الكتالوج وأدواته |
| `assets/js/site-experience.bundle.js` | تحسينات الأقسام والتجربة والواجهات المساندة |
| `assets/js/site-sections.bundle.js` | التنقل وعرض الأقسام |
| `assets/js/site-cloud.bundle.js` | إعداد Supabase ومزامنة البيانات المدعومة |
| `sw.js` | التخزين المؤقت ودعم العمل عند انقطاع الاتصال |
| `manifest.webmanifest` | بيانات تثبيت التطبيق |
| `data/products.json` وملفات الكتالوج | مصادر بيانات المنتجات حيث تكون مهيأة |

## تنظيم الكود

تم جمع ملفات JavaScript التي كانت تُحمّل منفردة في خمسة ملفات مجمعة، مع الحفاظ على ترتيب تنفيذها الأصلي. بقيت ملفات المصدر القديمة في المستودع كمرجع احتياطي؛ لا تحذفها قبل التحقق من النسخة المنشورة وإتمام اختبار الرجوع. ملف CSS الموحد هو المصدر الرئيسي للتنسيق لتجنب إضافة طبقات تصميم متكررة.

## البيانات والخصوصية

- لا تُعتبر الأسماء أو الأسعار أو الكميات غير المؤكدة بيانات مثبتة؛ راجعها من لوحة الإدارة قبل اعتمادها تجاريًا.
- لا تستبدل كتالوج المنتجات أو بيانات الإعدادات دون تصدير نسخة احتياطية أولًا.
- السلة والمفضلة قد تُحفظان محليًا في المتصفح. المزامنة السحابية متاحة فقط للبيانات التي يدعمها إعداد Supabase وسياسات الوصول الفعلية.
- لا تضع كلمات مرور أو مفاتيح سرية في ملفات الواجهة العامة. مفتاح Supabase العام ليس بديلًا عن سياسات RLS والمصادقة الصحيحة.
- رمز الإدارة المحلي وحده لا يوفّر حماية خادمية كاملة.

## التحقق قبل اعتماد الإصدار

1. افتح الموقع المنشور على الهاتف والكمبيوتر.
2. جرّب فتح القائمة والإعدادات والإدارة وكل الأقسام.
3. اختبر البحث، تفاصيل المنتج، اختيار الحجم والسعر، السلة، المفضلة، التركيب وطلب واتساب.
4. سجّل كلمة بحث غير موجودة ثم تحقق من ظهورها في تبويب «طلبات العملاء والبحث».
5. غيّر الثيم وأعد تحميل الصفحة للتحقق من بقاء الاختيار.
6. اختبر الاستيراد والتصدير والنسخ الاحتياطي، ثم تحقق من المزامنة السحابية من جلسة مصرح بها.
7. راجع سجل GitHub Actions وأخطاء المتصفح قبل اعتبار النشر ناجحًا.

**تنبيه:** تحديث ملفات GitHub لا يثبت وحده أن GitHub Pages اكتمل نشره أو أن كل الوظائف نجحت في متصفح فعلي. يجب تنفيذ الاختبارات أعلاه قبل اعتماد الموقع تجاريًا.
